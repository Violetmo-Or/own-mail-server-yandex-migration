# Безопасность

Проект работает с паролями и перепиской, поэтому об уязвимостях просим сообщать **приватно**, а не в открытом Issue: используйте вкладку **Security → Report a vulnerability** на GitHub.

Что важно помнить пользователю:
- пароли хранятся только в `config.env` на вашем сервере с правами 600 и не попадают в git (`.gitignore`);
- пароль приложения Яндекса можно в любой момент отозвать в настройках аккаунта;
- индекс поиска `mail-search.db` содержит текст вашей переписки, права только владельцу;
- защитный хук `.claude/hooks/guard.py` страхует от случайных ошибок ИИ-помощника, но не заменяет внимания человека.

*English: please report vulnerabilities privately via GitHub's "Report a vulnerability".*
